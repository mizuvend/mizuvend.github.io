Fitur Utama

Kelola seluruh operasional mesin vending Anda dari satu platform terintegrasi

Dashboard Interaktif

Peta real-time dengan lokasi seluruh mesin vending, status online/offline/disabled/error, dan metric bisnis.

  • Map dengan device markers
  • Status perangkat color-coded
  • Transaksi hari ini
  • Revenue bulan berjalan
  • Auto-refresh setiap menit

Manajemen Perangkat

Kontrol akses perangkat dengan role-based access, grant/remove device, dan monitoring per mesin.

  • Daftar perangkat dengan detail
  • Grant device access
  • Update device access roles
  • Remove/delete devices
  • View device details

Analitik Transaksi

Lihat riwayat transaksi, revenue trends, dan summary dengan berbagai filter waktu.

  • 7/30/90/180/365 hari
  • Bulan berjalan (MTD)
  • Tahun berjalan (YTD)
  • Custom date range
  • Tambah transaksi manual

Stok & Harga

Atur stok dan harga untuk 24 slot produk (kolom A & B, masing-masing 12 slot) secara real-time.

  • 24 slot management
  • Update stok per slot
  • Update harga per slot
  • Sinkronisasi langsung ke mesin

Pengaturan Mesin

Kontrol brightness LED, fridge relay, door coil, dan system control dari jarak jauh.

  • Button LED brightness
  • Bill display brightness
  • Backlight LED brightness
  • Fridge relay on/off
  • Enable/Disable/Restart mesin

Manajemen Tim

Multi-user access dengan role hierarchy, tambah member, update role, dan audit trail.

  • Tambah team member
  • Update role member
  • Remove member
  • Activity log / audit trail

Role-Based Access Control

Kontrol akses yang fleksibel sesuai kebutuhan organisasi Anda

OWNER

Owner

Full access termasuk update company name dan kelola semua members

  • Kelola company settings
  • Add/remove/update members
  • Grant/remove device access
  • Full dashboard access
ADMIN

Admin

Kelola devices dan team members, update device access

  • Add/remove devices
  • Manage team members
  • View all reports
  • Device configuration
TECHNICIAN

Technician

Akses device untuk troubleshooting dan maintenance

  • View assigned devices
  • Device troubleshooting
  • Update stock & price
  • Machine settings
VIEWER

Viewer

Read-only access untuk monitoring dan view reports

  • View dashboard
  • View transactions
  • View device status
  • Read reports

Cara Kerja

Mulai monitoring mesin vending Anda dalam 4 langkah mudah

1

Registrasi

Daftar akun perusahaan melalui website atau aplikasi monitoring kami

2

Hubungkan Perangkat

Masukkan device ID dan secret key untuk grant access ke mesin vending

3

Monitor

Pantau semua mesin melalui dashboard map interaktif secara real-time

4

Analisis

Lihat report transaksi dan revenue untuk keputusan bisnis yang tepat

Manfaat Software Kami

Transformasi cara Anda mengelola bisnis vending machine

Monitoring Real-time

Pantau semua mesin melalui peta interaktif dengan status online/offline/disabled/error. Auto-refresh setiap menit untuk data terkini.

Remote Management

Kelola stok, harga, dan pengaturan mesin dari jarak jauh tanpa perlu visit ke lokasi. Brightness control, fridge relay, dan system control.

Analitik Lengkap

Filter transaksi berbagai periode: 7/30/90/180/365 hari, MTD, YTD, atau custom range. Tambah transaksi manual untuk withdraw.

Team Collaboration

Multi-user access dengan 4 role: OWNER (full access), ADMIN (manage devices & members), TECHNICIAN (troubleshooting), VIEWER (read-only).

24-Slot Management

Kelola stok dan harga untuk 24 slot (kolom A & B, 12 slot each). Update langsung sinkronisasi ke mesin vending.

Audit Trail

Activity log mencatat semua aktivitas: login, logout, register, device changes, transaction updates untuk transparansi penuh.
